# LogTogether v0.10.3 — Science UX polish

v0.10.3 is a small UI/clarity correction on top of v0.10.2. It does not change the v0.10 science model, mission thresholds, Firestore rules, AppState schema, authorization, or family privacy boundaries.

## Fixes and polish

- Fixed Weekly Missions tutorial paging by rendering the active page directly; swipe, Previous/Next, and page dots now show the correct content.
- Kept exactly 10 Weekly Missions. The Personal Activity selector now lives inside the Personal Activity mission row so it no longer looks like an eleventh mission.
- Added clearer Health Guideline Progress layout and a short explanation that it is separate from game scoring.
- The quick guide now explains the 150 moderate-equivalent aerobic minute / 2 strength-day reference and that higher-intensity aerobic minutes count double in the app's equivalence display.
- Home now switches between `Weekly missions` and `Estimated calories`, while the existing weekly / 12-month calorie controls remain nested inside the calorie view.
- Renamed Workout Trend to `Estimated calorie trend`.
- Renamed the inner daily `Activity progress` label to `Gold Day progress`.
- Family Calories and Water comparison charts now use three subtle horizontal reference lines with rounded Y-axis values.
- Removed the calendar Gold Day star marker; the fixed gold day fill alone communicates Gold Day status.
- Bumped the PWA shell cache to `logtogether-shell-v0.10.3-polish`.
