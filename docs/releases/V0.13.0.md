# v0.13.0 — Clearer comparison, routine management, and workout handling

## Family comparison

- Weekly supplement review now shows the date, local time, amount, and unit for each entry.
- Family comparison uses the same expandable supplement detail when supplement sharing is enabled. The existing family profile sharing preference remains enabled by default for this family-and-friends alpha.
- Recent family workouts can be expanded to review recorded sets, repetitions, load, work duration, rest, effort, notes, and circuit rounds.
- Current-week difficulty is always republished during companion sync. Older summaries that have not yet been refreshed show “Needs sync” instead of an unexplained dash.

## Workout and routine experience

- Saved Routine Management starts with an empty chooser instead of silently opening the first routine.
- Selecting a routine reveals compact Edit, Load, and Delete actions near the top. Multi-select deletion remains available for removing several routines efficiently.
- Start Workout now presents Add Exercise first, then Add Circuit, then Saved Routine Management.
- While a workout timer is active, LogTogether removes focus from editable fields and cancels browser undo/redo input events on the workout page. This reduces accidental iPhone Shake to Undo prompts. iOS does not give installed web apps permission to disable that system gesture completely, so Settings also explains the device-level switch.

## Missions and exercise library

- Chosen Activity Days now requires one specific supported activity: hiking, swimming, running, cycling, or kickboxing.
- The previous “Any activity” and jump-rope mission choices no longer award new Chosen Activity progress. Existing backups and historical weekly plans remain readable.
- Basic jump rope appears under Home / Functional; Single Unders and Double Unders appear under Gym. All remain valid cardio exercise records.

## Photos and supplements

- History photos preserve the complete image instead of center-cropping it.
- Photos can be opened in a larger lightbox and closed with the backdrop, close button, or Escape key.
- Personal weekly supplement detail now includes time between date and amount.

## Privacy and compatibility

- Exact daily supplement documents remain readable only by their owner.
- When supplement family sharing is enabled, the weekly family summary contains at most 100 bounded entries with date, local `HH:mm` time, supplement identity, amount, and unit. It does not include private record IDs or full timestamps.
- Existing weekly summaries without detailed supplement entries remain valid.
- No new runtime dependency was added.

## Deployment safeguards

- `npm run verify:deploy-config` checks that the private local Firebase configuration is ignored by Git, copied into the built site, and still contains the approved Google Forms responder URL.
- `npm run verify:live` checks the deployed v0.13.0 app bundle, service-worker cache, and approved feedback form without printing the private runtime configuration.
- The service-worker cache is bumped so installed devices receive the v0.13.0 shell.

## Verification

- Production TypeScript build and unit tests cover chosen-activity matching, legacy mission values, jump-rope placement, family supplement detail, routine selection, photo display, and the workout undo mitigation.
- Firestore emulator tests cover owner-only supplement days, same-family weekly detail reads, and the 100-entry bound.
