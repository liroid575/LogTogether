# v0.17.0 — Workout readiness, fair Pokes, and activity expansion

v0.17.0 improves the moment a workout starts, makes Poke spending fair for every role, simplifies quick water and supplement logging, and expands the exercise library from 156 to 169 entries. Existing exercise IDs, completed records, routines, mission scoring, Gold Day thresholds, private heart-rate storage, and zero browser-runtime-dependency design remain intact.

## What changed

- Start buttons now honor an Off / 3 / 5 / 10 second pre-start countdown (default 5 seconds). The app gives one ready cue, displays a cancelable visual countdown, then writes `startedAt` only at GO with a double cue. Intentional in-app navigation cancels it, while switching apps keeps an absolute deadline so a throttled timer catches up once when LogTogether returns. Double taps cannot start two countdowns.
- The packaged timer cues have been remastered with conservative peak headroom, and fallback audio has a stronger, smoothly ramped Web Audio gain. Device mute behavior remains under operating-system control.
- History and Family Recent Activity put newest date groups first, then show activities oldest to newest within each date.
- Settings → Training experience is a closed disclosure with an at-a-glance status line for sounds, countdown, and screen wake.
- Family owners now spend Pokes from the same 0–7 wallet and follow the same sender cooldown as every other member. Owner-only local visual diagnostics remain available.
- Water and supplement quick logs always use the current time. Backdating and corrections remain available through the existing per-entry calendar editor.
- The last Beginner’s Guide page offers an explicit notification button with subscribed, incomplete, denied, unsupported, Local, and unconfigured states. Permission is never requested automatically.
- Taiwanese Traditional Chinese exercise and action copy was refined, including 深蹲（徒手）, 站姿提踵, 負重提踵, 訓練體驗, and the completed-activity prompt.
- A new **Dance & Mind-body** group adds K-pop / Pop Dance, Dance Cardio, Barre / Ballet Fitness, Mat Pilates, and generic VR Boxing / Combat Fitness.
- Practical mobility adds front/back and lateral leg swings, 90/90 switches, adductor rock-backs, Cossack squat mobility, frog/adductor stretch, and deep squat hold.
- Standing Cross-Body Knee Drive records both repetitions per side and actual interval time. It contributes through active cardio time and does not masquerade as strength volume.
- New session activities use optional perceived effort and conservative activity-specific MET ranges for calorie trends. Calories remain estimates and never determine missions, Gold Days, Pokes, or badges.

## Dev v2 testing pass

- Recently used supplements now appear first without duplicates. Choosing one restores the last logged amount and unit under an explicit “Last logged” label; it is never presented as dose advice.
- Screen wake has Off, During workouts, and While LogTogether is open modes, with bounded retry after lifecycle release. Portrait lock and a workout-scoped stable-view preference degrade safely when unsupported and never disable zoom across the app.
- Completed-activity logging and History editing can add, replace, or remove a photo through the existing local IndexedDB image path. Images are re-encoded to WebP and are not uploaded to Firebase.
- Saved routines remain visible on Home as equal horizontal cards. Family notification settings are collapsed with status and Poke balance in the summary.
- The active-workout dock now exposes only the current action: Start, Finish, Return from rest, or Finish workout. Returning from Home or another page scrolls to the active control and respects reduced motion.
- Hydration rolls over by local date on startup, focus, pageshow, visibility return, and a foreground minute check. The Water refresh button reconciles local day state without reloading or touching an active workout.
- Family keeps the last synced membership and summaries readable during temporary offline/auth recovery, with an explicit cached-data message.
- Weekly Momentum celebrates the 8/10 weekly qualification crossing, while Gold Day burst summaries distinguish unique people from the number of daily events.
- Repeated difficulty labels use the shared Taiwanese terminology helper: 輕鬆、一般、困難、極限.

The dev-v2 pass deliberately does not add a fake media session, background audio loop, permanent manifest orientation lock, global pinch-zoom restriction, daily streak, Firebase photo upload, or full-page refresh. Mobile browsers may suspend audio in the background; the app corrects the timer state and attempts one catch-up cue on return but cannot promise an audible background beep.

## Privacy and security

No new collection, third-party service, analytics tool, browser runtime package, location field, or shared health metric was added. Heart rate remains in the owner-only private metrics document. VR entries store activity duration and optional private heart rate; they do not ingest game accounts, game scores, device calorie claims, or brand-specific identifiers.

The pre-start countdown is transient UI state and is never stored or synced. Notification permission is requested only from a direct button press. Poke wallet deduction, cooldown, mute checks, visibility checks, and recipient flood protection remain server-side.

## Research and standards basis

- The 2024 Adult Compendium lists dance activities across a wide intensity range, including general ballet/modern/jazz at 5.0 MET, ballet exercises at 6.3 MET, cultural dance at 4.5 MET, and aerobic Chinese square dance at 7.3 MET. LogTogether therefore uses ranges selected by effort instead of one universal dance number.
- A systematic review comparing structured dance with other structured exercise supports treating dance as meaningful physical activity, while not turning a broad genre label into a medical promise.
- Recent Pilates metabolic evidence is explicitly limited and heterogeneous. The Pilates estimate is therefore conservative and labeled as an estimate.
- Mobility defaults distinguish controlled dynamic repetitions from sustained static holds. The app gives practical timing guidance without injury-prevention claims.
- VR combat fitness is intentionally generic. Its estimate uses duration and perceived effort rather than a game’s score or advertised calorie number.
- Notification permission remains tied to a user gesture, and the settings disclosure uses native HTML disclosure behavior.
- Web Audio gain changes use short ramps to avoid abrupt waveform changes.

## Validation

Run before deployment:

```bash
MISE_QUIET=1 mise exec node@22 -- npm test
MISE_QUIET=1 mise exec 'java@temurin-21.0.12+101.0.LTS' node@22 -- npm run test:security
MISE_QUIET=1 mise exec node@22 -- npm audit --omit=dev
MISE_QUIET=1 mise exec node@22 -- npm audit --prefix functions --omit=dev
```

At release preparation, both deployable dependency audits report zero vulnerabilities. The complete root development audit reports three moderate findings in `firebase-tools@15.31.0` through its `@google-cloud/pubsub` / `@opentelemetry/core` toolchain. They are not included in the browser build, the current Firebase CLI release has no compatible fix for them, and no forced dependency upgrade is applied.
