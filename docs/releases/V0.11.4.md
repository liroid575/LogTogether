# LogTogether v0.11.4 — Workout Flow & Feedback Polish

This release is a focused testing patch built on v0.11.3. It does not change the science scoring model or Cloud authorization architecture.

## Timer reliability

Start and Finish use one short cue. A configured work/rest target reaching zero uses a two-cue deadline alert once and then displays overtime. Work and rest have separate deadline acknowledgements. Timer sound continues using the transient/mixing browser audio mode; on iPhone the Ring/Silent switch can still suppress the cue.

## Ordered workout flow

Only the next canonical set or circuit movement can Start or Skip. Skip requires confirmation. A skipped item is stored as an explicit optional state for History but is not completed work, so it contributes no calories, muscle/training credit, missions, Gold Day score, progression evidence, PRs or Pokes. A workout where every item was skipped cannot be saved as a completed workout.

Exercise-level Work and Rest controls now sit together for applicable rep-based exercises. Changing the Work target updates only future unstarted sets.

A Discard workout control is available beneath the workout name from the moment a draft/routine/circuit is selected.

## Social and notification feedback

The private social inbox listener starts with active Cloud membership instead of waiting for a Family/Settings visit. Foreground Pokes can therefore display the sender popup and restrained emoji rain anywhere in the app.

The Family notification reminder is shown whenever social categories are enabled and the current device is not subscribed, unless the user explicitly selected “Never show this reminder again.” Blocked/unsupported states provide guidance rather than silently suppressing the prompt.

## Milestone feedback

Gold Day, daily water-goal and monthly badge transitions have lightweight CSS/DOM celebrations. They are keyed so refreshes do not replay them and reduced-motion users receive a static treatment.

## Cloud connection UX

Interactive Google sign-in/access verification now has a global LogTogether-branded progress overlay. Local data remains untouched until valid Cloud access is confirmed.

## Deployment

Hosting-only. Existing Firestore rules/indexes, Functions, VAPID secrets and science data remain unchanged.
