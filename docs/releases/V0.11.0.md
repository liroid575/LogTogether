# LogTogether v0.11.0 — Family testing, home exercise & social encouragement

This release moves LogTogether from repeated UI polishing into family testing while adding the most requested practical features.

## Exercise and workout changes

- New **Home & Functional** exercise group for accessible at-home strength, balance and support-endurance work.
- Jump-rope variants use a consistent interval/round recording profile.
- Optional rest-timer completion beep generated with the browser Web Audio API.
- Optional Screen Wake Lock while a workout is active; the app reacquires it when returning to the foreground when possible.
- Water and Supplements use a section-level **Edit / Done** mode.

## Social notifications and Pokes

- Users explicitly opt in to browser push notifications on each device.
- Notification categories can be disabled independently for Gold Days, badges and Pokes.
- A newly earned Gold Day can grant one Poke, capped at five stored Pokes.
- Pokes use only the approved emoji set: 👋 💪 🎉 🔥 🫡.
- Pokes require authenticated active family membership, mutual group visibility and App Check.
- The same sender cannot Poke the same recipient again for two hours.
- Recipients can disable Poke notifications globally.

## Privacy and infrastructure

- Push subscription endpoints and keys are stored only under the signed-in user's private Firestore path.
- Social functions run in `asia-east1` and send small Web Push payloads directly to the browser push service.
- VAPID public/private keys are stored as Firebase Functions secrets.
- Firebase Cloud Functions deployment requires the Blaze plan; usage for a small family should remain far below normal free-tier quotas.

## Compatibility

- AppState remains schema v1.
- Existing workouts and routines remain readable.
- The v0.10 science-scoring model and safety exclusions remain intact.
