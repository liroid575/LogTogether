# LogTogether v0.10.4 — Home trend layout polish

v0.10.4 is a small presentation fix on top of v0.10.3. It does not change exercise science, Weekly Mission thresholds, Gold Day scoring, family comparison logic, Firestore rules, AppState schema, authorization, or privacy boundaries.

## Changes

- Rebuilt the Home Estimated Calories pane as an explicit one-column responsive panel so its title, period selector and chart cannot split into separate columns.
- Preserved both the Weekly and 12-month calorie views and the existing week navigation.
- Renamed the Home help control from **What are Weekly Missions?** to **Quick Guide** and made it visually lighter.
- Retained the **4-week momentum** name and added the inline explanation **Weeks with 8+ missions completed.**
- Changed the neutral default account/profile name from **Family member** to **User**. Existing chosen names are untouched; the legacy placeholder is still recognized as a placeholder when joining Cloud.
- Bumped the service-worker shell cache to `logtogether-shell-v0.10.4-polish`.
