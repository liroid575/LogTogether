# v0.17.0 activity and UX audit

This audit records the design boundary behind the v0.17.0 additions. It is a product and recording audit, not medical advice.

| Area | Recording decision | Scoring boundary | Evidence / standard |
| --- | --- | --- | --- |
| K-pop / Pop Dance | Duration + perceived effort; 20-minute starter | Active cardio time; 4.5–7.3 MET estimate range | 2024 Adult Compendium dance entries; PMID 29270864 |
| Dance Cardio | Duration + perceived effort; 20-minute starter | Active cardio time; 5.0–8.0 MET estimate range | 2024 Adult Compendium dance entries |
| Barre / Ballet Fitness | Duration + perceived effort | Mobility/meaningful activity; no fabricated resistance sets; 3.0–5.0 MET | Compendium ballet and slow dance values; conservative lower bound |
| Mat Pilates | Duration + perceived effort | Core/mobility display; no fabricated resistance sets; 2.8–4.8 MET | PMID 41495794; evidence described as limited and heterogeneous |
| VR Boxing / Combat Fitness | Duration + perceived effort; optional private HR | Active cardio time; no game score or device calorie input; 5.0–9.0 MET | PMID 38833285; generic activity name avoids product lock-in |
| Standing Cross-Body Knee Drive | 2 intervals × 20 reps/side, 45 s active, 45 s recovery | Cardio time from actual active duration; no strength-set farming | Conservative conditioning interval model |
| Dynamic hip mobility | 2 × 8 controlled reps/side | Mobility active time when timed; no injury claims | Dynamic mobility is separated from static holds |
| Static adductor / deep squat holds | 2 × 30 s, 15 s transition | Mobility time | Existing static-stretch model; practical circuit consistency |
| Start countdown | Off / 3 / 5 / 10 s; default 5 | Transient and unsynced | Native disclosure/ARIA semantics; reduced-motion support |
| Notifications | Explicit guide button only | No automatic permission request | MDN Notifications API |
| Audio cues | Packaged cues raised with about 2.8 dB peak headroom; smooth attack/release to 0.38 fallback gain | No volume slider or audio-session takeover | MDN GainNode / Web Audio |
