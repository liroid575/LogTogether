# UI Polish v0.8.3 Preview 3

Small final polish pass before deployment.

Changes in this preview:
- Normal workout cards visually aligned more closely with circuit rows.
- Compact inline delete icon for normal workout exercise cards.
- Start buttons made larger for easier tapping.
- Per-set duration now shown under the started time when available.
- Circuit effort changed from per-movement/per-set to one effort rating per round.
- Package version bumped to 0.8.3-ui-preview.3.

Notes:
- This is still a local preview build.
- If building from a fresh extracted folder, run `npm install` before `npm run build`.
