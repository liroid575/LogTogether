# LogTogether v0.6.3 focused polish

Small frontend-only cleanup based on phone testing.

## Changes
- Water/supplement bottom-nav icon enlarged substantially.
- History calendar reverted to one workout dot per active workout day.
- Hike triangle remains.
- Daily calorie-goal days now use the selected accent/theme color instead of hydration blue.
- Removed the generated stick-figure exercise icons from workout cards and History.
- Add Exercise now shows a simple `View image examples` link for the currently selected exercise; it opens a Google Images search in a new tab.
- Family member badges are split into separate Monthly badges and Hiking badges sections.
- Service-worker cache bumped to `logtogether-shell-v0.6.3`.

No Firestore rules or backend code changed.
