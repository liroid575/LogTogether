# LogTogether v0.9.0 — Activity-aware workouts

## Workout lifecycle
- A workout draft does not create the persistent dock or Home "Current workout" card.
- Starting the first set/session makes the workout active.
- The active dock persists across tabs and includes a working Discard action until Finish or confirmed Discard.
- Home and the dock use the same started-workout state.

## Cloud member administration
- Owner Cloud members & access is read-only by default.
- Edit exposes group assignment and revoke/restore controls; Done returns to the clean view.
- Re-entering Settings defaults back to the clean view.

## Activity-aware logging
- Strength/bodyweight: sets, reps/weight or timed sets, rest and effort.
- Cardio sessions: one session instead of fake sets. Machines expose useful fields such as duration, distance, speed, incline and/or resistance where relevant.
- Swimming: duration/distance/laps where relevant; treading-water skills remain time based.
- Mobility/stretching: duration-oriented sessions.
- Boxing/kickboxing duration work: round-oriented logging with round rest.

## Training credit
- Compound strength sets split one credit across the muscles involved rather than duplicating a full set into every category.
- Cardio and mobility earn separate, capped time-based credit.
- Live timed-session credit uses actual completed time when timing data exists, falling back to logged duration for older/manual records.
- Effort 1–5 only makes a modest adjustment (about 0.85x to 1.10x).
- Weekly missions, monthly badge scoring, family exercise mix, and calendar exercise mix use the weighted model.
- The calculation is documented in Settings > Calculations & version.

## Compatibility
- Firestore rules and indexes are unchanged.
- Existing workout schema remains v1; new session metrics are optional fields.
- Old records remain readable.
