# LogTogether v0.8.3.2

Small Cloud/workout polish update:

- Empty workout drafts no longer keep the active workout dock after discard.
- Removed the End rest action from the persistent workout dock.
- Existing Cloud members can reconnect from a fresh browser/incognito session without retaining the original invite link.
- Owner-only Cloud member administration stays private to the owner; regular members get a read-only same-group member list.
- Owner profile group visibility moved inside the Groups foldout.
- Invite controls now appear after Cloud member administration and include a locally generated QR code.
- Monthly workout trend navigation resets to the current calendar year when returning to Home.
- Calculations & version now documents the BMI formula and cutoffs used by LogTogether.
